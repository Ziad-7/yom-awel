# Feedback Quality Rubric

Member 1 reviews release examples from Eng. Tarek using six dimensions scored from 0 to 2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Factual grounding | Contradicts or invents evaluator facts | Mostly grounded with an unclear claim | Matches decision, score, and referenced checks |
| Business relevance | No workplace consequence | Generic consequence | Specific consequence tied to the failed or passed check |
| Actionability | No usable next step | Broad suggestion | One targeted next action without giving the solution |
| Egyptian Arabic | Unreadable or inappropriate | Understandable but unnatural | Clear, culturally appropriate Egyptian Arabic |
| Professionalism | Harassing, blaming, or identity-claiming | Inconsistent tone | Concise, respectful supervisor tone |
| Solution non-disclosure | Reveals a reference answer | Overly prescriptive | Guides without disclosing the reference solution |

A release example must score 2 for factual grounding and solution non-disclosure, score at
least 9/12 overall, remain within 900 Unicode characters, and receive Member 1 approval.
Live-model prose is reviewed by properties and this rubric; tests must not depend on exact
live-model wording.
