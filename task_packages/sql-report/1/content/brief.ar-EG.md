# تقرير المبيعات باستخدام SQL

نزّل ملف المبيعات CSV واكتب استعلام `SELECT` واحدًا بلغة SQLite على جدول اسمه `sales`.
أعمدة الجدول هي `order_id` و`region` و`status` و`quantity` و`unit_price`.

أرجع صفًا واحدًا لكل منطقة بها طلبات **مدفوعة**. يجب أن يحتوي الناتج على الأعمدة التالية بهذا الترتيب:

1. `region` — اسم المنطقة.
2. `paid_orders` — عدد الطلبات التي فيها `status = 'paid'`.
3. `total_revenue` — مجموع `quantity * unit_price` للطلبات المدفوعة، مقربًا إلى منزلتين عشريتين.

لا تُدخل الطلبات المعلّقة أو الملغاة. احفظ الاستعلام في ملف `.sql` بترميز UTF-8 وارفعه، أو استخدم محرر الاستعلام داخل الموقع. يُقبل استعلام قراءة واحد فقط ولا يمكن تعديل بيانات المهمة.

ابدأ بهذا الهيكل وأكمله بنفسك:

```sql
SELECT region, ...
FROM sales
WHERE ...
GROUP BY region;
```
